# Relay — Autonomous Enterprise HR Operating System

Relay is the Autonomous Enterprise HR and Regulatory Intelligence Operating System developed for enterprise workforce operations and localized KSA statutory compliance (GOSI, WPS, Qiwa, Muqeem, Mudad).

## Features
- **Autonomous Multi-Agent Orchestration**: 15 specialized domain agents.
- **KSA Statutory Compliance**: Real-time GOSI recalculation, automated WPS pre-flight reconciliation, dual-custody audit traces.
- **Enterprise Design**: Clean, high-contrast Ramp-inspired aesthetic.
